# C++ Project

## Overview

This project provides a modern C++ development setup using:

- Nix flakes for reproducible environments
- CMake + Ninja as the build system
- `just` as a command runner
- clang tooling (`clang-format`, `clang-tidy`, `clangd`)
- optional sanitizers
- built-in testing and benchmarking

It is designed to scale from small projects to larger systems without changing structure.

---

## Getting Started

Enter the development shell:

    nix develop

Or enable automatic loading:

    direnv allow

---

## Project Layout

    .
    ├── flake.nix
    ├── justfile
    ├── CMakeLists.txt
    ├── cmake/
    ├── include/
    ├── src/
    ├── tests/
    ├── bench/
    └── build/

- `src/` — implementation files
- `include/` — public headers
- `tests/` — unit tests
- `bench/` — benchmarks
- `build/` — generated artifacts

## Build System Notes

- CMake handles all compilation and dependency tracking
- Ninja is used as the backend generator
- `compile_commands.json` is generated by CMake and symlinked to the project root

---

## Editor Integration

For `clangd`:

    just compdb

This ensures the language server sees correct compile flags.

---

## Reproducibility

- `flake.lock` pins compiler, tools, and system dependencies
- The development shell ensures consistent environments across machines

---

## Extending the Project

Common next steps:

- add new libraries via `add_library(...)` in CMake
- introduce external dependencies via `FetchContent`
- split into multiple targets (libraries, executables)
- add proper benchmarking frameworks (e.g. Google Benchmark)

---

## Philosophy

- CMake is the source of truth for builds
- `just` is a thin ergonomic wrapper
- the template stays minimal but scalable
